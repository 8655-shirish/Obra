# Contractor's Website Builder

Obra builds and hosts websites for US contractors. The current monthly subscription plans are:

- **Starter — $79/month:** website, hosting, editing, Website Leads, and email support.
- **Pro — $129/month:** website hosting and editing, Google Calendar booking, and visitor payments through Stripe Connect.

There is no setup fee. Live charging and booking remain operationally gated until production migrations, providers, workers, schedules, and canary evidence are complete.
